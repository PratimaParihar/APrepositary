# Online Shopping Portal Automation Framework

## Overview

This project is a Selenium WebDriver Automation Framework developed to automate the testing of an Online Shopping Portal. The framework validates critical e\-commerce functionalities such as user authentication, product search, cart management, checkout process, and order confirmation.

The framework follows industry\-standard automation practices using Java, Selenium WebDriver, TestNG, and Maven.

## How to Execute Tests

### Clone Repository

git clone [https://github.com/yourusername/your\-repository.git](https://github.com/yourusername/your-repository.git)

### Install Dependencies

mvn clean install

### Run Tests

mvn test

### Execute Specific TestNG Suite

mvn test \-DsuiteXmlFile=testng.xml
